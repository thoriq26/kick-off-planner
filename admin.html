ADMIN PANEL
Panduan Owner / Admin
  1. Pilih komunitas aktif pada selector di header. Semua data dan RLS mengikuti komunitas tersebut.
  2. Di Data Pemain, pilih member yang sudah memiliki akun, tentukan posisi, lalu tambahkan ke daftar.
  3. Di Info Match Day, isi detail pertandingan, nominal admission fee, pembayaran, dan paste seluruh kode iframe Google Maps. Klik PUBLISH MATCH agar member dapat melihatnya.
  4. Setelah member mengunggah bukti transfer, buka daftar Bukti Transfer Masuk untuk melihat, menyetujui, atau menolak bukti. Setelah keputusan dibuat, gunakan tombol EDIT jika status perlu diperbaiki.
  5. Gunakan RESET untuk memulai info match baru atau ARCHIVE untuk menyimpan riwayat. Keduanya tidak boleh digunakan hanya untuk mencoba tampilan.
Cara Pakai - Data Pemain
  1. Tambah pemain: pilih member yang sudah memiliki akun, pilih posisi, lalu klik "TAMBAH PEMAIN".
  2. Edit: klik ikon pensil hijau pada baris pemain, ubah data, klik "SIMPAN PERUBAHAN".
  3. Hapus satu pemain: klik ikon tong sampah merah pada baris yang dituju.
  4. Hapus semua pemain: klik "RESET SEMUA" — dipakai setelah pertandingan selesai / mau mulai pendaftaran baru. Aksi ini tidak bisa dibatalkan.
  5. Data di sini otomatis dipakai saat melakukan Undi Tim di tab sebelah.

Cara Pakai - Undi Tim
  1. Pastikan data pemain di tab "Data Pemain" sudah lengkap.
  2. Pilih jumlah tim (2/3/4) lalu klik SHUFFLE — pemain akan diacak merata berdasarkan posisi.
  3. Pemain berstatus SPECTATOR (FAN) otomatis tidak diikutkan undian.
  4. Klik RESET untuk membatalkan pembagian tim dan mengundi ulang dari awal.
  5. Hasil undian ini akan tampil kepada member komunitas di halaman Team Draft.

Cara Pakai - Info Match Day
  1. Isi nama event, lapangan, tanggal & jam, warna jersey, admission fee, informasi pembayaran, dan lokasi.
  2. Untuk lokasi, wajib pakai kode embed iframe dari Google Maps — bukan link share biasa (yang formatnya https://maps.app.goo.gl/xxxxxxx).
    Cara mendapatkannya: buka lokasi di Google Maps → klik Bagikan / Share → pilih tab Sematkan peta / Embed a map → klik Salin HTML, lalu tempel utuh ke kolom "LINK / EMBED GOOGLE MAPS".
    Contoh kode yang benar:
    <iframe src="https://www.google.com/maps/embed?pb=!1m18!1m12!1m3!1d3964.888739754436!2d106.8511666!3d-6.4083312!2m3!1f0!2f0!3f0!3m2!1i1024!2i768!4f13.1!3m3!1m2!1s0x2e69ebfd405f8217%3A0x1bce6016d5cfbd0f!2sBSS%20Arena%20Depok!5e0!3m2!1sid!2sid!4v1790069563556!5m2!1sid!2sid" width="600" height="450" style="border:0;" allowfullscreen="" loading="lazy" referrerpolicy="strict-origin-when-cross-origin"></iframe>
    Sistem otomatis mengambil bagian src="..." dari kode tersebut, jadi tidak masalah kalau kode iframe ditempel utuh seperti contoh di atas.
  3. Setelah semua data benar, klik PUBLISH MATCH. Member kemudian dapat melihat info, melakukan registrasi, dan mengunggah bukti transfer.
  4. Periksa Bukti Transfer Masuk setelah ada-member yang mengunggah file. Klik ikon mata untuk melihat, centang untuk menyetujui, atau silang untuk menolak.
  5. Setelah pertandingan selesai, klik ARCHIVE untuk menyimpan data ke riwayat pertandingan (bisa dilihat member komunitas di halaman Event History) dan otomatis mengosongkan daftar pemain — siap untuk event berikutnya.
  6. Klik RESET jika hanya ingin mengosongkan info tanpa menyimpan ke riwayat.
