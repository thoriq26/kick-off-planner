Cara Pakai - Data Pemain
  1. Tambah pemain: pilih member yang sudah memiliki akun, pilih posisi, lalu klik "TAMBAH PEMAIN".
  2. Edit: klik ikon pensil hijau pada baris pemain, ubah data, klik "SIMPAN PERUBAHAN".
  3. Hapus satu pemain: klik ikon tong sampah merah pada baris yang dituju.
  4. Hapus semua pemain: klik "RESET SEMUA" — dipakai setelah pertandingan selesai / mau mulai pendaftaran baru. Aksi ini tidak bisa dibatalkan.
  5. Data di sini otomatis dipakai saat melakukan Undi Tim di tab sebelah.

Cara Pakai - Undi Tim
  1. Pastikan data pemain di tab "Data Pemain" sudah lengkap.
  2. Pilih jumlah tim (2/3/4) lalu klik ACAK TIM — pemain akan diacak merata berdasarkan posisi.
  3. Pemain berstatus SPECTATOR (FAN) otomatis tidak diikutkan undian.
  4. Klik ULANGI PEMBAGIAN untuk membatalkan pembagian tim dan mengundi ulang dari awal.
  5. Hasil undian ini akan tampil kepada member komunitas di halaman Team Draft.

Cara Pakai - Info Match Day
  1. Isi detail pertandingan, jadwal, admission fee, pembayaran, dan lokasi.
  2. Untuk lokasi, gunakan kode embed iframe Google Maps, bukan link share biasa.
  3. Klik PUBLIKASIKAN agar anggota dapat melihat dan mengunggah bukti transfer.
  4. Gunakan RESET untuk pertandingan baru atau ARSIPKAN untuk menyimpan riwayat.

Cara Pakai - Undangan
  1. Buat kode undangan untuk komunitas ini.
  2. Kirim tautan undangan menggunakan tombol WhatsApp, Telegram, atau Bagikan Lainnya. Kode akan otomatis terisi di halaman onboarding.
  3. Klik LIHAT DAFTAR di Undangan Aktif untuk melihat nama dan email akun yang sudah memakai kode undangan tersebut.
  4. Kode dapat kedaluwarsa atau dibatalkan dari daftar undangan.
